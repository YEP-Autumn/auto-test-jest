## 2. 组网与拓扑

```text
   逻辑端口 A -- DUTA PortB
   DUTA PortA   <=> DUTB PortA
   DUTB PortB   <=> DUTC PortB
   DUTC PortC   <=> DUTD PortC
   DUTD PortD   <=> DUTA PortD
   DUTC PortA   -- 逻辑端口 B
```

拓扑名称 / 来源：`four_devices_topo_links_type_6`（内置拓扑）。

| 链路                      | 网段            | 端点地址                               | 开销    |
| ------------------------- | --------------- | -------------------------------------- | ------- |
| 逻辑端口 A ↔ DUTA PortB | 198.51.100.0/24 | A 侧 198.51.100.1，测试仪 198.51.100.2 | 1       |
| A-B                       | 10.0.12.0/24    | A=10.0.12.1，B=10.0.12.2               | 1 / 1   |
| B-C                       | 10.0.23.0/24    | B=10.0.23.1，C=10.0.23.2               | 1 / 1   |

| DUTC PortA ↔ 逻辑端口 B | 203.0.113.0/24  | C 侧 203.0.113.1，测试仪 203.0.113.2   | 1       |

A 到 203.0.113.0/24 的主路径为 A-B-C，LFA 明细中的备份下一跳为 A-D-C 的 `10.0.41.1`。

## 3. 预置条件

### 3.1 协议基线参数

| 参数         | 取值                             | 说明                             |
| ------------ | -------------------------------- | -------------------------------- |
| OSPF 进程    | 0（`router ospf`）               | 同一 VRF 仅支持一个进程          |
| Area         | 0                                | 单区域                           |
| Network Type | point-to-point                   | 避免广播网络 DR/BDR 影响切换时间 |
| LFA          | `fast-reroute per-prefix enable` | 在初始 OSPF 配置中使能           |
| BFD          | 不配置                           | 本用例唯一变量：无 IP BFD        |

### 3.2 初始状态

- 接口处于默认二层状态；OSPF、Loopback、L3 地址、静态 ARP 和 LFA 配置为空。
- 拓扑后端已建立四设备环及两个测试仪接入链路。
- 现场保留：默认清理。

### 3.3 流量参数

| 参数     | 取值                                 | 说明                               |
| -------- | ------------------------------------ | ---------------------------------- |
| 发送端口 | 逻辑端口 A                       | 接入 DUTA PortB                    |
| 接收端口 | 逻辑端口 B                       | 从 DUTC PortA 收包                 |
| 报文     | IPv4/UDP，198.51.100.2 → 203.0.113.2 | 目的地址属于 LFA 受保护前缀        |
| 包间隔   | 1ms                                  | 1 个丢包约等于 1ms 中断            |
| 发送数量 | 5000 个                              | 发送时长约 6~8s                    |
| 判据     | 接收匹配数 > 4950                    | 即丢包 < 50，表示切换中断小于 50ms |

## 4. 测试步骤与预期结果

### 4.1 配置

四台设备的接口、Loopback 与 OSPF 配置与 [0042](0042-IP_ROUTE-OSPF_LFA.md) 的 4.1 相同，并删除全部 `bfd interval` 和 `ip ospf bfd` 命令。DUTA 增加测试仪接入口 `198.51.100.1/24`，DUTC 增加测试仪出口 `203.0.113.1/24` 和静态 ARP `arp 203.0.113.2 0002.0002.0002`。

### 4.2 基线检查与执行顺序

| 顺序 | 动作 | 命令 / 触发方式 | 预期 |
| --- | --- | --- | --- |
| 1 | 邻居基线检查 | `show ip ospf neighbor` | 四台设备的两条邻居均为 `Full` |
| 2 | 主路径基线 | `show ip route 203.0.113.2` | 下一跳为 `10.0.12.2` |
| 3 | LFA 明细基线 | `show ip ospf fast-reroute per-prefix` | 目标前缀的备份下一跳为 `10.0.41.1` |
| 4 | 启动流量发送与抓包 | 见 4.3 | 发送 5000 个报文，接收端开始计数 |
| 5 | 本地接口 shutdown | 见 4.3 | 路由切换到 `10.0.41.1`，丢包少于 50 个 |

本用例仅验证故障切换，回切不作为判定项，因此不设 4.4 恢复步骤。

### 4.3 触发与流量发送

1. 在逻辑端口 B 启动抓包。
2. 逻辑端口 A 以 1ms 间隔发送 5000 个报文。
3. 发送约 4s 后，在 DUTA 上关闭 `<PortA>`，不依赖 BFD。
4. 等待路由切换到 `10.0.41.1`，并确认 `ping 3.3.3.3` 为 `0% packet loss`。
5. 停止发送和抓包，统计接收匹配数。

| 触发 / 观测项 | 操作或方法 | 预期 |
| --- | --- | --- |
| 本地接口故障 | DUTA `<PortA>` 执行 `shutdown` | 路由切换到 `10.0.41.1`（A-D-C） |
| LFA 表 | `show ip ospf fast-reroute per-prefix` | 目标前缀存在备份 `10.0.41.1` |
| 接收匹配数 | 逻辑端口 B 抓包统计 | 大于 4950 个（丢包小于 50 个） |
| 切换后路由 | `show ip route 203.0.113.2` | 下一跳为 `10.0.41.1`（A-D-C） |
| 切换后连通性 | `ping 3.3.3.3` | `0% packet loss` |

### 4.5 观测面

| 观测面 | 命令 / 方法 | 判定 |
| --- | --- | --- |
| 协议状态面 | `show ip ospf neighbor` | 故障前四台设备的两条邻居均为 `Full`；故障后 A-B 邻居中断 |
| LFA 明细面 | `show ip ospf fast-reroute per-prefix` | 目标前缀存在备份下一跳 `10.0.41.1` |
| 表项面 | `show ip route 203.0.113.2` | 故障前 `10.0.12.2`；故障后 `10.0.41.1` |
| 转发面 | 逻辑端口 B 抓包统计、`ping 3.3.3.3` | 接收匹配大于 4950 个（丢包小于 50 个）；`ping 3.3.3.3` 丢包率为 0% |
| 测量面 | 1 包/ms 折算 | 丢包数近似等于切换中断毫秒数 |

历史实测记录（2026-11-18）：

```text
Captured 4982 packet(s)
Found 4979 matching packet(s)
丢包 = 5000 - 4979 = 3
```

按 1 包/ms 折算，无 BFD 时本地接口 shutdown 的切换中断约 3ms。

### 4.6 判定标准

- 4.2 步骤 1 至 3 全部满足：四台设备的两条邻居均为 `Full`，主路径下一跳为 `10.0.12.2`，目标前缀的备份下一跳为 `10.0.41.1`。
- 4.3 流量发送满足：接收匹配大于 4950 个，丢包小于 50 个，折算切换中断时间小于 50ms；切换后 `203.0.113.2` 下一跳为 `10.0.41.1`，`ping 3.3.3.3` 丢包率为 0%。
- 上述条件全部满足且第 5 章清理成功：结论为 `Pass`。
- 上述条件任一不满足：结论为 `Fail`。
- 设备不支持 LFA、拓扑后端无法建立四设备环，或测试仪无法稳定按 1ms 间隔发送并计数：结论为 `Blocked`，记录缺失项与现场。

## 5. 清理与恢复

四台设备删除 OSPF 进程、Loopback、接口地址和静态 ARP，恢复接口二层状态。本用例仅验证故障切换，回切不作为判定项。
