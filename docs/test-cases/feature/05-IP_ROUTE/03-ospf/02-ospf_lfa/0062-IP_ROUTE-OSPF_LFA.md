## 2. 组网与拓扑

```text
   StreamPort.A -- DUTA PortB
   DUTA PortA   <=> DUTB PortA
   DUTB PortB   <=> DUTC PortB
   DUTC PortC   <=> DUTD PortC
   DUTD PortD   <=> DUTA PortD
   DUTC PortA   -- StreamPort.B
```

内置拓扑：`LinkConstraint.four_devices_topo_links_type_6`。

| 链路                      | 网段            | 端点地址                               | 开销    |
| ------------------------- | --------------- | -------------------------------------- | ------- |
| StreamPort.A ↔ DUTA PortB | 198.51.100.0/24 | A 侧 198.51.100.1，测试仪 198.51.100.2 | 1       |
| A-B                       | 10.0.12.0/24    | A=10.0.12.1，B=10.0.12.2               | 1 / 1   |
| B-C                       | 10.0.23.0/24    | B=10.0.23.1，C=10.0.23.2               | 1 / 1   |
| C-D                       | 10.0.34.0/24    | C=10.0.34.1，D=10.0.34.2               | 1 / 1   |
| D-A                       | 10.0.41.0/24    | D=10.0.41.1，A=10.0.41.2               | 10 / 10 |
| DUTC PortA ↔ StreamPort.B | 203.0.113.0/24  | C 侧 203.0.113.1，测试仪 203.0.113.2   | 1       |
| Loopback0                 | 主机路由        | A=1.1.1.1/32，B=2.2.2.2/32，C=3.3.3.3/32，D=4.4.4.4/32 | 1 |

A 到 203.0.113.0/24 的主路径为 A-B-C，LFA 明细中的备份下一跳为 A-D-C 的 `10.0.41.1`。

## 3. 预置条件

### 3.1 协议基线参数

| 参数         | 取值                             | 说明                             |
| ------------ | -------------------------------- | -------------------------------- |
| OSPF 进程    | 0（`router ospf`）               | 同一 VRF 仅支持一个进程          |
| Area         | 0                                | 单区域                           |
| Network Type | point-to-point                   | 避免广播网络 DR/BDR 影响切换时间 |
| LFA          | `fast-reroute per-prefix enable` | 在初始 OSPF 配置中使能           |
| BFD          | 不配置                           | 本用例唯一变量：无 IP BFD        |

### 3.2 流量参数

| 参数     | 取值                                 | 说明                               |
| -------- | ------------------------------------ | ---------------------------------- |
| 发送端口 | `StreamPort.A`                       | 接入 DUTA PortB                    |
| 接收端口 | `StreamPort.B`                       | 从 DUTC PortA 收包                 |
| 报文     | IPv4/UDP，198.51.100.2 → 203.0.113.2 | 目的地址属于 LFA 受保护前缀        |
| 包间隔   | 1ms                                  | 1 个丢包约等于 1ms 中断            |
| 发送数量 | 5000 个                              | 发送时长约 6~8s                    |
| 判据     | 接收匹配数 > 4950                    | 即丢包 < 50，表示切换中断小于 50ms |

### 3.3 初始状态

- 接口处于默认二层状态；OSPF、Loopback、L3 地址、静态 ARP 和 LFA 配置为空。
- 拓扑后端已建立四设备环及两个测试仪接入链路。

## 4. 测试步骤与预期结果

### 4.1 配置

四台设备配置 OSPF 点对点接口、Loopback 和 LFA，不配置任何 BFD。DUTA 增加测试仪接入口 `198.51.100.1/24`，DUTC 增加测试仪出口 `203.0.113.1/24` 和静态 ARP。

### 4.2 基线观测

| 观测项   | 命令                                   | 预期                             |
| -------- | -------------------------------------- | -------------------------------- |
| 邻居     | `show ip ospf neighbor`                | 四台设备的两条邻居均为 `Full`    |
| 主路径   | `show ip route 203.0.113.2`            | 下一跳为 `10.0.12.2`             |
| LFA 明细 | `show ip ospf fast-reroute per-prefix` | 目标前缀备份下一跳为 `10.0.41.1` |

### 4.3 流量发送与本地 shutdown

1. 在 `StreamPort.B` 启动抓包。
2. `StreamPort.A` 以 1ms 间隔发送 5000 个报文。
3. 发流约 4s 后，在 DUTA 上关闭 `<PortA>`，不依赖 BFD。
4. 等待路由切到 `10.0.41.1`，并 `ping 3.3.3.3` 为 `0% packet loss`。
5. 停止发送和抓包，统计接收匹配数。

| 观测项       | 预期                               |
| ------------ | ---------------------------------- |
| LFA 表       | 目标前缀存在备份 `10.0.41.1`       |
| 接收匹配数   | 大于 4950（丢包小于 50）           |
| 切换后路由   | `10.0.41.1`（A-D-C）               |
| 切换后连通性 | `ping 3.3.3.3` 为 `0% packet loss` |

### 4.4 实测切换时间

本次执行：

```text
Captured 4982 packet(s)
Found 4979 matching packet(s)
丢包 = 5000 - 4979 = 3
```

按 1 包/ms 折算，无 BFD 时本地接口 shutdown 的切换中断约 **3ms**。

## 5. 清理与恢复

四台设备删除 OSPF 进程、Loopback、接口地址和静态 ARP，恢复接口二层状态。本用例只测故障切换，回切不作为判定项。

## 6. 备注 / 标准裁剪

| #   | 项       | 说明                                                                |
| --- | -------- | ------------------------------------------------------------------- |
| 1   | 测量方式 | 1 包/ms，丢包数近似等于中断毫秒数；不是高精度时间戳测量             |
| 2   | 对照关系 | 与 0042 相同拓扑和流量，仅去掉 BFD；0042 丢包 9，本用例丢包 3       |
| 3   | 结论定位 | 当前镜像下，仅靠本地接口 shutdown 也能在 50ms 内触发 LFA 数据面切换 |
| 4   | 判据方向 | 以“丢包 < 50”作为无 BFD 时本地 shutdown 的切换判据              |
