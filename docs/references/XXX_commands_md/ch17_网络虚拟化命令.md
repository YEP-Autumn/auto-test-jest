# 17 网络虚拟化命令

## 17.1 Overlay 命令

### 17.1.1 `vlan overlay enable`

**功能**：使用此命令使能或去使能vlan 的overlay 功能。

**语法**：

```
vlan VLAN_ID overlay ( enable | disable )
```

| 参数 | 说明 |
| --- | --- |
| VLAN_ID |  |
| Vlan id | 2-4094 |
| enable | 使能vlan 的overlay 功能 |
| disable | 去使能vlan 的overlay 功能，默认vlan 的overlay 功能是去使能的 |

**命令模式**：VLAN 配置模式

**默认配置**：去使能

**使用说明**：

在配置overlay 的vlan 和vni 的映射关系之前需要先使能vlan 的overlay 功能

**示例**：

```
下面的例子显示了使能vlan 2 的overlay 功能:

Switch# configure terminal
Switch(config)# vlan database
Switch(config-vlan)# vlan 2
Switch(config-vlan)# vlan 2 overlay enable
```

**相关命令**：无

### 17.1.2 `overlay`

**功能**：使用此命令进入OVERLAY 配置模式。 使用关键词exit 退出OVERLAY 配置模式。

**语法**：

```
overlay
```

**命令模式**：全局配置模式

**默认配置**：无

**使用说明**：

无

**示例**：

```
下面的例子显示了如何进去OVERLAY 配置模式:
Switch# configure terminal
Switch(config)# overlay
Switch(config-overlay)#
```

**相关命令**：无

### 17.1.3 `vlan vni`

**功能**：使用此命令配置vlan 和vni 的映射关系。

**语法**：

```
vlan VLAN_ID vni VNI
no vlan VLAN_ID vni
```

| 参数 | 说明 |
| --- | --- |
| VLAN_ID |  |
| Vlan id | 2-4094 |
| VNI | vni 值 1-16777215 |

**命令模式**：OVERLAY 配置模式

**默认配置**：无

**使用说明**：

该命令用于绑定vlan 和overlay 的vni 的关系，这就意味着一旦一个vlan 和vni 绑定了，
  vlan 下所有的端口也就属于vni 的广播域了，并且可以在vni 的广播域内进行单播，组
  播和广播了。

**示例**：

```
下面的例子显示了设置vlan 和vni 的映射:
Switch# configure terminal
Switch(config)# overlay
Switch(config-overlay)# vlan 20 vni 20000
下面的例子显示了如何删除vlan 和vni 的映射:
Switch# configure terminal
Switch(config)# overlay
Switch(config-overlay)# no vlan 20 vni
```

**相关命令**：无

### 17.1.5 `source`

**功能**：使用该命令为overlay 设置全局源vtep 的ip 地址。
  使用关键词no 删除overlay 的全局源vtep 的ip 地址。

**语法**：

```
source IP_ADDR

no source
```

| 参数 | 说明 |
| --- | --- |
| IP_ADDR | Overlay 的vtep 的源地址， 必须是是一个有效的ip 地址 IPv4 地址 |

**命令模式**：OVERLAY 配置模式

**默认配置**：无

**使用说明**：

Overlay vtep 的源地址用于对overlay 的原始报文进行加封装和解封装。建议源地址采
  用某个3 层口地址（比如环回口）以保证该地址的路由是可达的。

**示例**：

```
下面的例子显示了如何配置overlay 的源地址:
Switch# configure terminal
Switch(config)# overlay
Switch(config-overlay)# source 1.1.1.1
下面的例子显示了如何删除overlay 的源地址:
Switch# configure terminal
Switch(config)# overlay
Switch(config-overlay)# no source
```

**相关命令**：无

### 17.1.6 `remote-vtep`

**功能**：使用此命令配置overlay 的peer。
  使用关键词no 来删除overlay 的peer。

**语法**：

```
remote-vtep INDEX ip-address IP_ADDR_VTEP type ( vxlan | nvgre | geneve ) ( { src-ip
IP_ADDR | split-horizon-disable | keep-vlan-tag } | )
no remote-vtep index
```

| 参数 | 说明 |
| --- | --- |
| INDEX | 远端vtep 的索引 1-65535 |
| vxlan-peer | 远端的vtep 类型是VxLAN - |
| nvgre-peer | 远端的vtep 类型是NvGRE - |
| geneve-peer | 远端的vtep 类型是 |
| GENEVE |  |
| IP_ADDR_VTEP | Overlay 远端vtep 的地址， 必须是一个有效的ip 地址 IPv4 地址 |
| IP_ADDR | Overlay 源端vtep 的地址，必须是一个有效的ip 地址，缺省情况下取 全局 sourc ip。 IPv4 地址 |
| horizon-split-disable | 该vtep 上支持配置的 tunnel ，关闭水平分割。 |
| keep-vlan-tag | 指定是否剥除原始报文的外层VLAN 标签。 |

**命令模式**：OVERLAY 配置模式

**默认配置**：无

**使用说明**：

此命令用于创建overlay 的远端vtep 的类型和地址，管理员应该知晓整个网络上的所
  有peer，并且保证他们之间是路由可达的。

**示例**：

```
下面的例子创建了一个远端的vxlan 的vtep:
Switch# configure terminal
Switch(config)# overlay
Switch(config-overlay)# remote-vtep 20 ip-address 2.2.2.2 type vxlan src-ip 1.1.1.1

下面的例子删除了一个远端的vxlan 的vtep:
Switch# configure terminal
Switch(config)# overlay
Switch(config-overlay)# no remote-vtep 20
```

**相关命令**：无

### 17.1.7 `dscp-strategy`

**功能**：使用此命令配置overlay 的外层IP DSCP 获取方式。

**语法**：

```
remote-vtep INDEX encapsulation-dscp-strategy ( dscp-copy | priority-map | custom-
assign VALUE )
```

| 参数 | 说明 |
| --- | --- |
| INDEX | 远端vtep 的索引 1-65535 |
| dscp-copy | 外层dscp 值从内层报文 dscp 值复制而来 |
| priority-map | 外层dscp 值从priority 值映射而来 custom-assign VALUE) 外层dscp 值由用户指定具体值 0-63 |

**命令模式**：OVERLAY 配置模式

**默认配置**：dscp-copy 模式

**使用说明**：

使用priority-map 模式时，需要用户配置MQC 来配置具体的priority 值，具体做法参
  照MQC 部分的CLI 命令

**示例**：

```
下面的例子配置vtep 的dscp 获取模式为custom-assign:
Switch# configure terminal
Switch(config)# overlay
Switch(config-overlay)# remote-vtep 20 dscp-strategy custom-assign 63
```

**相关命令**：无

### 17.1.8 `Virtual-mac`

**功能**：使用此命令配置overlay 的远端vtep 的虚拟mac 地址。
  使用关键词no 形式删除remote-vtep 的virtual-mac。

**语法**：

```
remote-vtep INDEX virtual-mac MAC
no remote-vtep index virtual-mac
```

| 参数 | 说明 |
| --- | --- |
| INDEX | 远端vtep 的索引 1-65535 |
| MAC | MAC 地址 |

**命令模式**：OVERLAY 配置模式

**默认配置**：无

**使用说明**：

此命令用于配置overlay 的远端vtep 的虚拟mac 地址，当DVR 的路由没有指定inner
  的mac 目的地址时，将采用其remote vtep 的虚拟mac 地址作为inner 的mac 目的地
  址。

**示例**：

```
下面的例子配置了远端vtep 的虚拟mac 地址:

Switch# configure terminal
Switch(config)# overlay
Switch(config-overlay)# remote-vtep 20 virtual-mac a.a.a
下面的例子删除远端vtep 的虚拟mac 地址:
Switch# configure terminal
Switch(config)# overlay
Switch(config-overlay)# no remote-vtep virtual-mac
```

**相关命令**：无

### 17.1.10 `overlay uplink`

### 17.1.13 `ip route remote-vtep`

**功能**：使用该命令配置overlay 的静态DVR 路由。使用该命令的no 形式删除静态DVR 路由

**语法**：

```
ip route vrf VRF_NAME ( ADDRESS WILDCARD-MASK | ADDRESS/PREFIX-LENGTH )
remote-vtep INDEX vni VNI ( | inner-macda mac-addr )
no ip route vrf VRF_NAME ( ADDRESS WILDCARD-MASK | ADDRESS/PREFIX-LENGTH )
remote-vtep INDEX vni VNI ( | inner-macda mac-addr )
```

| 参数 | 说明 |
| --- | --- |
| VRF_NAME | Vrf 名字不超过31 个字符的字符串 |
| ADDRESS | IPv4 地址 IPv4 地址 |
| WILDCARD-MASK | Ip 子网掩码 IPv4 地址 |
| PREFIX-LENGTH | Ip 前缀长度 1-32 |
| INDEX | 远端vtep 的索引 1-65535 |
| VNI | vni 值 1-16777215 |
| MAC_ADDR | 内层报文的目的mac 地址 MAC 地址 |

**命令模式**：全局配置模式

**默认配置**：无

**使用说明**：

无

**示例**：

```
下面的例子配置了一条overlay 的静态路由:
Switch# configure terminal
Switch(config)# ip route vrf tenant1 3.3.3.3/32 remote-vtep 3 vni 50000 inner-macda
a.a.a
Switch(config)# ip route vrf tenant1 4.4.4.4/32 remote-vtep 3 vni 50000
下面的例子删除了一条overlay 的静态路由:
Switch# configure terminal
Switch(config)# no ip route vrf tenant1 3.3.3.3/32 nvgre-peer 5.5.5.5 vni 50000
inner-macda a.a.a
Switch(config)# no ip route vrf tenant1 4.4.4.4/32 nvgre-peer 5.5.5.5 vni 50000
```

### 17.1.17 `qos tunnel-aware inner`

**功能**：使用在未使能overlay 解封装端口上， 强制使用overlay 报文的内层头部信息作ACL 或
  者Flow tracing.

**语法**：

```
( no | ) qos tunnel-aware inner
```

| 参数 | 说明 |
| --- | --- |
| no | 对Overlay 报文不使用内层头部信息 |

**命令模式**：端口配置模式

**默认配置**：去使能

**使用说明**：

此命令在以太网端口上使能。对于做Tunnel 解封装的报文， 解完封装后会继续解析报
  文内层头部信息; 对于未做tunnel 解封装的overlay 报文， 如果希望使用报文内层头部
  信息作ACL、Flow tracing 等处理， 可以通qos tunnel-aware inner 这条命令来实现。

**示例**：

```
下面的例子使能端口上的内层报文头信息功能:
Switch# configure terminal
Switch(config)# interface eth-0-1
Switch(config-if)#  qos tunnel-aware inner
```

**相关命令**：无

## 17.2 OVSDB 命令

### 17.2.1 `ovsdb enable`

**功能**：使用此命令使能OVSDB 功能。使用相应的no 命令关闭OVSDB 功能

**语法**：

```
ovsdb enable ( management-ip IP_ADDR | ) ( none-mgmt-if | )
no ovsdb enable
```

| 参数 | 说明 |
| --- | --- |
| IP_ADDR | 配置OVSDB 的管理地址， 该地址将会添加到VTEP 数据库中 IPv4 地址 |
| none-mgmt-if | 配置客户端到OVSDB 服务器的连接通过带内口 |

**命令模式**：全局配置模式

**默认配置**：OVSDB 功能未使能

### 17.3.10 `neighbor route-reflector-client`

| TAG | 已经存在的对等组名。请参考neighbor peer-group， neighbor remote-as 命令来创建对等组。当这个参数被命令使用的时候，这个命令会被应用到指定组的所有对等体上。 |

  由于AS 可以有多个RR。一个RR 把另外一个RR 作为另外一个iBGP speaker 来对待。

**示例**：

```
Switch# configure terminal

```
