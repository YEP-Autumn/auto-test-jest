## 1.3 符号约定

### 表1-1命令语法规则

**表1-1 命令语法规则**

| 格式 | 意义 |
|---|---|
| 斜体大写字母 | 命令行参数（命令中必须由实际值进行替代的部<br>分）采用斜体大写字母表示。 |
| (x\|y\|…) | 表示从若干个选项中选取一个。 |
| (x\|y\|…\|) | 表示从若干个选项中选取一个或者不选。 |
| [x\|y\|…] | 表示从若干个选项中选取一个或多个，每个选项<br>可以重复被选择。 |

| [x\|y\|…\|] | 表示从若干个选项中选取一个、多个或不选，每<br>个选项可以重复被选择。 |
|---|---|
| {x\|y\|…} | 表示从若干个选项中选取一个或多个，每个选项<br>只能被选取一次。 |
| {x\|y\|…\|} | 表示从若干个选项中选取一个、多个或不选，每<br>个选项只能被选取一次。 |
| <x-y> | 表示从指定范围内选择一个数值。 |
