# ASCII 拓扑图绘制指南

## 0. 目的与适用范围

本文约定 `utils/runtime/topologies/catalog.ts` 中拓扑注释的 ASCII 图绘制方法，适用于以下场景：

- `LinkConstraint` 各拓扑 getter 上方的拓扑说明；
- 用例文档、设计文档中的组网示意图；
- 评审、问题定位和现场复现时使用的临时拓扑图。

适用版本：当前仓库版本。`catalog.ts` 的拓扑定义变更后，应同步复核本指南中的示例。本指南的范围限于图形绘制方法。

本文使用的术语约定如下：

- `链路` 指设备间的逻辑连接；`连线` 指图中表示链路的线条；`线段` 指连线中的一段；
- `设备方框` 指表示设备的矩形框，下文简称 `方框`；
- `端口标签` 指写在链路旁边的 `PortA`、`PortB` 等文本；
- `StreamPort` 指测试仪端口；
- `DUTA`、`DUTB` 等表示被测设备（Device Under Test，DUT）。

本文使用 ASCII（American Standard Code for Information Interchange）字符绘制拓扑图。拓扑图用于表达设备、端口和链路关系；图按示意图方式绘制。绘制人员应满足以下要求：

1. 设备、端口和链路均可从图中直接读出；
2. 每条链路的两个端点都落在设备方框边界上；
3. 每条链路使用独立线段，连接关系可独立识别；
4. 图中应完整表达每台设备的接口和链路关系，所有连接均通过连线和端口标签表达；
5. 布局满足以下判据：同一行方框顶边对齐，同一列方框左边框对齐，相邻分支间距相等，端口标签与方框的间距符合 5.6。

关联文档：[文档编写规范](documentation-convention.md)；拓扑定义见 [`catalog.ts`](../../utils/runtime/topologies/catalog.ts)。

## 1. 基本元素

### 1.1 设备方框

设备统一使用 10 字符宽的方框。示例：

```text
+--------+
|  DUTA  |
+--------+
```

需要在一侧绘制 2 条以上链路时，可使用加高方框；加高后从左右边框引出的链路仍按 5.6 的间距规则标注。示例：

```text
+--------+
|        |
|  DUTA  |
|        |
+--------+
```

约定：

- 方框默认宽度为 10 字符；当单侧需要引出 2 条以上链路，或端口标签无法与方框保持 5.6 规定的间距时，扩展方框宽度；
- 方框扩展后，端口标签与引出线对齐，同一行方框顶边对齐；
- 方框内设备名居中，两侧各保留至少 1 个空格；
- 方框左边框、右边框使用 `|`，四角使用 `+`；
- 方框高度在同一张图中保持一致；宽度可以统一，也可以根据连线需要调整，同一行方框宽度保持一致。

### 1.2 端口标签

端口标签统一写成 `PortA`、`PortB`、`PortC`、`PortD` 等形式。

约定：

- 水平链路在链路两端分别标注本端端口标签和对端端口标签；
- 垂直链路沿竖线在两端分别标注本端端口标签和对端端口标签；
- 同一端口标签可以在不同设备上重复；同一链路的两个端点应分别标注端口标签；
- StreamPort 接口写成 `StreamPort.A`、`StreamPort.B`；
- 端口标签与设备方框的间距按 5.6 的规则执行。

### 1.3 链路符号

链路符号用于表示设备间的双向连接。水平链路和垂直链路分别按以下方式绘制。

水平链路示例：

```text
+--------+                   +--------+
|  DUTA  |--PortA <=> PortA--|  DUTB  |
+--------+                   +--------+
```

垂直链路示例：

```text
+--------+
|  DUTA  |
+---+----+
    |
  PortA
    |
  PortA
    |
+---+----+
|  DUTB  |
+--------+
```

约定：

- 水平直连的双向链路统一使用 `<=>`；
- 水平链路写成 `--PortX <=> PortY--`；
- 垂直链路使用 `|`，端口标签写在竖线两端；
- 需要拐角的链路使用 `-`、`|` 和 `+` 绘制；
- 线路转弯处使用 `+`。

### 1.4 StreamPort

StreamPort 表示测试仪端口。放置 StreamPort 时，StreamPort 标签与相邻设备或链路之间应保留至少 1 列空白。

水平放置示例：

```text
                        +--------+
StreamPort.A <=> PortD--|  DUTA  |
                        +--------+
```

垂直放置示例：

```text
      StreamPort.A
            |
          PortE
            |
       +----+---+
       |  DUTA  |
       +--------+
```

约定：

- StreamPort 与设备之间同样应标注端口标签；
- StreamPort 水平放置时，设备方框的上、下边框保持完整，连接线落在左边框或右边框上；
- StreamPort 垂直放置时，StreamPort 标签、端口标签、竖线和设备方框中心线使用同一列，保持居中对齐；
- 同一设备使用 2 个以上 StreamPort 时，可将它们分布在设备的不同方向，并优先选择不与其它链路交叉的位置；
- StreamPort 的连接线从设备间链路之外通过。

### 1.5 注释块

拓扑图放在 getter 上方的 JSDoc 注释中。JSDoc 是 JavaScript 的文档注释格式。示例：

```ts
/**
 * 拓扑说明：
 *
 *   +--------+                   +--------+
 *   |  DUTA  |--PortA <=> PortA--|  DUTB  |
 *   +--------+                   +--------+
 */
static get <topoLinksGetter>(): TopoLinks {
  // 返回拓扑定义
}
```

约定：

- 注释使用 `/** ... */` 形式；
- 注释内容与 getter 紧邻；
- 注释块中的拓扑图每行以 `*` 开头，并保持 `*` 与注释块左边界对齐；
- 注释中的 `<topoLinksGetter>` 替换为实际的 getter 名称。

## 2. 基本画法

### 2.1 水平直连

适用于两台设备之间的单条链路。示例：

```text
+--------+                   +--------+
|  DUTA  |--PortA <=> PortA--|  DUTB  |
+--------+                   +--------+
```

链路两端分别标注本端端口标签和对端端口标签。

### 2.2 并行链路

适用于同一对设备之间的 2 条以上链路。并行链路应逐条绘制，按行排列，并在每条链路的两端分别标注端口标签。示例：

```text
+--------+                   +--------+
|        |--PortA <=> PortA--|        |
|  DUTA  |                   |  DUTB  |
|        |--PortB <=> PortB--|        |
+--------+                   +--------+
```

图中两条链路分别使用 `PortA` 和 `PortB`，两端端口标签一一对应。

### 2.3 垂直链路

适用于上下排列的设备。端口标签写在竖线两端。示例：

```text
+--------+
|  DUTA  |
+---+----+
    |
  PortD
    |
  PortD
    |
+---+----+
|  DUTD  |
+--------+
```

当一对设备之间有 2 条以上垂直链路时，每条链路使用独立竖线。

### 2.4 绕线路径

当设备无法直接并排时，使用横线、竖线和 `+` 拐角绕线。示例：

```text
+--------+                   +--------+
|  DUTA  |--PortA--+         |  DUTB  |
+--------+         |         +---+----+
                   |             |
                   +--PortB------+
```

约定：

- 绕线路径由水平段和垂直段组成；
- 绕线路径的拐角使用 `+`；
- 绕线路径从设备方框外侧通过；
- 每条绕线路径使用独立线段。

## 3. 布局模式

### 3.1 单设备与链式

设备数量为 1～3 台时，优先使用水平排列。示例：

```text
+--------+                   +--------+                   +--------+
|  DUTA  |--PortA <=> PortA--|  DUTB  |--PortB <=> PortB--|  DUTC  |
+--------+                   +--------+                   +--------+
```

链式布局中，相邻设备之间使用单条水平链路连接。

### 3.2 两行与方阵

设备数量为 4 台且存在环形或交叉链路时，使用 2×2 方阵。示例：

```text
+--------+                   +--------+
|  DUTA  |--PortA <=> PortA--|  DUTB  |
+---+----+                   +---+----+
    |                            |
  PortD                        PortB
    |                            |
  PortD                        PortB
    |                            |
+---+----+                   +---+----+
|  DUTD  |--PortC <=> PortC--|  DUTC  |
+--------+                   +--------+
```

方阵布局中，同一行设备之间使用水平链路连接，同一列设备之间使用垂直链路连接。

### 3.3 环形

环形拓扑使用 2×2 方阵，四边分别表示四条链路。示例：

```text
                        +--------+                   +--------+
StreamPort.A <=> PortB--|  DUTA  |--PortA <=> PortA--|  DUTB  |
                        +---+----+                   +---+----+
                            |                            |
                          PortD                        PortB
                            |                            |
                          PortD                        PortB
                            |                            |
                        +---+----+                   +---+----+
                        |  DUTD  |--PortC <=> PortC--|  DUTC  |
                        +--------+                   +---+----+
                                                         |
                                                       PortA
                                                         |
                                                   StreamPort.B
```

图中 StreamPort.A 放在左侧，StreamPort.B 放在下方；四条链路首尾相接，StreamPort 通过独立链路接入 DUTA 和 DUTC。

### 3.4 分层布局与绕线

设备数量为 5～6 台且链路数量大于设备数量时，将链路数量最多的设备放在中间层，其它设备放在上层或下层。当链路无法直连时，按 2.4 的方式绕线。示例：

```text
+--------+                   +--------+
|  DUTD  |--PortC <=> PortA--|  DUTB  |
+---+----+                   +---+----+
    |                            |
  PortD                        PortB
    |                            |
  PortD                        PortB
    |                            |
+---+----+                   +---+----+
|  DUTA  |--PortA <=> PortA--|  DUTC  |
+---+----+                   +---+----+
    |                            |
  PortB                        PortC
    |                            |
  PortA                        PortC
    |                            |
+---+----+                   +---+----+
|  DUTE  |--PortB <=> PortB--|  DUTF  |
+--------+                   +--------+
```

分层布局中，同一行设备使用水平链路连接，同一列设备使用垂直链路连接。分层布局和绕线时，先保证端点落在方框边界上，再调整中间路径。垂直链路的上下两端都应标注端口标签。

### 3.5 星形与扇出

星形与扇出用于单台设备连接 2 台以上设备。它既包含局部分叉点的画法，也包含整体布局方式。

**局部分叉点**

分叉与汇聚用于表示一条连线在图中分为 2 个以上分支，或 2 个以上分支汇入同一设备。分叉点用 `+` 表示；设备使用方框表示。示例：

```text
  +-------------------------------------+
  |                DUTA                 |
  +----+----------------------------+---+
       |                            |
     PortA                        PortB
       |                            |
     PortA                        PortA
       |                            |
  +----+---+                   +----+---+
  |  DUTB  |                   |  DUTC  |
  +--------+                   +--------+
```

分叉点用于组织图形；分叉前后每个分支都应标注本端端口标签和对端端口标签，并能追溯到中心设备的具体端口。

**备选方案：紧凑框分叉点**

分支为 2 条且端口标签之间保留至少 1 列空白时，可以使用紧凑中心框。示例：

```text
                 +--------+
                 |  DUTA  |
                 +----+---+
                      |
          +-----------+-----------+
          |                       |
        PortA                   PortB
          |                       |
        PortA                   PortA
          |                       |
      +---+----+             +----+---+
      |  DUTB  |             |  DUTC  |
      +--------+             +--------+
```

紧凑框方案同样要求分叉点用 `+` 表示，并在分叉前后标注本端端口标签和对端端口标签。

**整体星形布局**

单台设备连接 4 台以上设备时，将中心设备放在上方或左侧，相邻分支间距相等。StreamPort 的放置位置应满足：StreamPort 标签与相邻链路之间保留至少 1 列空白，连接线从设备间链路之外通过。示例：

```text
  +-----------------------------------------------------+
  |                        DUTA                         |
  +----+--------------+--------------+--------------+---+
       |              |              |              |
     PortC          PortA          PortB          PortD
       |              |              |              |
     PortA          PortA          PortA          PortA
       |              |              |              |
  +----+---+     +----+---+     +----+---+     +----+---+
  |  DUTD  |     |  DUTB  |     |  DUTC  |     |  DUTE  |
  +--------+     +--------+     +--------+     +--------+
```

宽框示例展示设备间的星形连接。实际拓扑中存在 StreamPort 时，按 1.4 的方式补全。

**备选方案：紧凑框星形**

分支为 3 条且端口标签之间保留至少 1 列空白时，可以使用紧凑中心框。示例：图中同时展示 StreamPort 的放置方式。

```text
                        +--------+
StreamPort.A <=> PortD--|  DUTA  |
                        +----+---+
                             |
               +-------------+-------------+
               |             |             |
             PortA         PortB         PortC
               |             |             |
             PortA         PortA         PortA
               |             |             |
          +----+---+    +----+---+    +----+---+
          |  DUTB  |    |  DUTC  |    |  DUTD  |
          +--------+    +--------+    +--------+
```

分支为 4 条以上，或端口标签间距小于 2 列时，优先使用宽框方案。

约定：

- 每个分支从中心设备的不同端口分别引出；
- 分叉点用于组织图形，端口标签用于表达连接关系。

## 4. 绘制流程

### 4.1 链路清单

绘制拓扑图前，先整理设备、链路和端口，整理完成后再绘图。链路清单如下：

| 本端设备 | 本端端口 | 对端设备 | 对端端口 |
| -------- | -------- | -------- | -------- |
| `DUTA`   | `PortA`  | `DUTB`   | `PortA`  |
| `DUTA`   | `PortB`  | `DUTC`   | `PortA`  |
| `DUTB`   | `PortB`  | `DUTF`   | `PortA`  |

链路清单用于绘制前核对；拓扑图仍通过连线和端口标签表达连接关系。

### 4.2 端口数量核对

示例：另一张拓扑的端口数量统计如下。

| 设备   | 已用端口（个） | 可用端口（个） |
| ------ | -------------- | -------------- |
| `DUTA` | 5              | 6              |
| `DUTB` | 3              | 6              |
| `DUTE` | 2              | 4              |

已用端口数量超出可用端口数量时，应先调整拓扑，再按调整后的链路绘图。

### 4.3 布局选择

| 条件                                | 推荐布局                 |
| ----------------------------------- | ------------------------ |
| 1 台设备                            | 单设备居中               |
| 2 台设备                            | 水平并排                 |
| 3 台设备                            | 水平链式                 |
| 4 台设备且存在交叉链路              | 2×2 方阵                 |
| 4 台设备且四条链路首尾相接          | 环形                     |
| 5～6 台设备且链路数量不超过设备数量 | 星形布局（见 3.5）       |
| 5～6 台设备且链路数量大于设备数量   | 分层布局与绕线（见 3.4） |
| 单台设备连接 4 台以上设备           | 星形布局（见 3.5）       |

设备数量和连接形态同时满足多行条件时，按更具体的场景选择。

### 4.4 设备方框绘制

按以下步骤绘制设备方框：

1. 按默认宽度绘制所有设备方框。
2. 当单侧需要引出 2 条以上链路，或端口标签无法与方框保持 5.6 规定的间距时，扩展方框宽度。
3. 确定每台设备的位置，使同一行方框顶边对齐、同一列方框左边框对齐。

### 4.5 链路绘制

按链路清单逐条绘制。

绘制步骤：

1. 优先使用水平或垂直直线。
2. 当链路无法直连时，使用 `+` 拐角绕线。

绘制约束：

- 每条链路单独占用线段；
- 链路端点应落在设备方框边界上；
- 每条链路使用独立线段和已标注的连接点；
- 绘制链路时，确保设备名始终可见。

### 4.6 端口标注

每条链路绘制完成后，立即在两端标注端口标签：

- 水平链路：`--PortA <=> PortA--`；
- 垂直链路：沿竖线在两端分别标注端口标签；
- 绕线链路：在起点和终点标注端口标签，拐角附近可重复标注以便阅读。

### 4.7 StreamPort 添加

最后添加 StreamPort，根据图中剩余空白选择放置位置，并按 1.4 的规则保持间距。

### 4.8 绘制结果自检

绘制完成后，按第 7 节清单逐项检查。

## 5. 连接与对齐规则

### 5.1 连接点位置

链路端点应落在方框的 `+` 或边框上。为使连接关系明确，推荐使用 `+` 连接点。示例：

```text
+--------+
|  DUTA  |
+---+----+
    |
  PortA
    |
+---+----+
|  DUTB  |
+--------+
```

链路应直接连接到方框边界；端点与方框边界之间保持连续连接。链路端点与方框边界重合时，连接关系成立。

### 5.2 链路与线段

每条链路应单独占用线段。分叉点用于组织图形；分叉后的每个分支应单独标注端口标签，并能追溯到中心设备的具体端口。各链路使用独立线段；需要共享线段时，在分叉点明确标注。示例：

```text
+--------+
|  DUTA  |
+---+----+
    |
  PortA
    |
    +------------------+
                       |
                     PortA
                       |
                  +----+---+
                  |  DUTB  |
                  +--------+

+--------+
|  DUTA  |
+---+----+
    |
  PortB
    |
    +------------------+
                       |
                     PortB
                       |
                  +----+---+
                  |  DUTC  |
                  +--------+
```

当链路从方框侧面横向进入时，连接点应位于方框侧边的垂直中心。示例：

```text
+--------+
|  DUTA  |
+---+----+
    |
  PortA
    |
    |                  +--------+
    +-----------PortA--|  DUTB  |
                       +--------+
```

### 5.3 方框宽度与对齐

方框默认使用 10 字符宽度。满足以下任一条件时，扩展方框宽度：

- 单侧需要引出 2 条以上链路；
- 绕线路径需要额外空间；
- 扩展后交叉点数量减少，或端口标签与方框的间距符合 5.6。

扩展方框时，应同时满足：

- 设备名居中，方框四角使用 `+`；
- 同一行设备的中心线或边框保持对齐；
- 端口标签与引出线保持对齐；方框扩展后对齐关系保持不变；
- 方框宽度变化应有明确目的；同一行方框宽度保持一致。

### 5.4 两端端口标签

链路两端都应标注端口标签，以便判断对端端口。水平链路和垂直链路均按此规则执行。

### 5.5 符号约定

同一张图中使用以下符号：

- `<=>` 表示水平直连的双向链路；
- `|` 表示垂直链路；
- `-` 表示水平链路；
- `+` 表示拐角、分叉或方框角；
- `StreamPort.X` 表示测试仪端口。

同一张图中的水平直连链路统一使用 `<=>`；垂直链路和绕线链路统一使用 `|`、`-`、`+`。

### 5.6 端口标签与方框的间距

端口标签与设备方框之间采用固定间距，具体规则如下。

**水平链路示例**

端口标签写在链路中间，端口标签与两侧方框之间各保留至少 2 个 `-`。

```text
+--------+                   +--------+
|  DUTA  |--PortA <=> PortA--|  DUTB  |
+--------+                   +--------+
```

**垂直链路示例**

方框与第一个端口标签之间保留 1 行 `|`，2 个端口标签之间保留 1 行 `|`，最后一个端口标签与下一方框之间保留 1 行 `|`。

```text
+--------+
|  DUTA  |
+---+----+
    |
  PortA
    |
  PortA
    |
+---+----+
|  DUTB  |
+--------+
```

**端口标签靠近方框顶部或底部的示例**

端口标签与方框连接点之间保留 1 行 `|`。

```text
                     PortA
                       |
                  +----+---+
                  |  DUTB  |
                  +--------+
```

**端口标签靠近方框侧面的示例**

端口标签与方框边框之间保留至少 2 个 `-`。

```text
    |                  +--------+
    +-----------PortA--|  DUTB  |
                       +--------+
```

**宽框底部引出的示例**

宽框底部 `+` 连接点与端口标签之间、端口标签与下方设备顶部连接点之间，均保留 1 行 `|`。

```text
       |
     PortA
       |
     PortA
       |
  +----+---+
  |  DUTB  |
  +--------+
```

统一要求：

- 水平方向在端口标签与方框边框之间保留至少 2 个 `-`；
- 垂直方向在端口标签与方框之间保留 1 行 `|`；
- 同一张图使用统一的间距；
- 端口标签文字以链路所在列为基准居中对齐。

## 6. 常见错误与修正

| 错误             | 现象                                       | 修正                                                   |
| ---------------- | ------------------------------------------ | ------------------------------------------------------ |
| 连线悬空         | 连线停在方框上方或下方                     | 将连线延伸至方框边界，并使用 `+` 连接点                |
| 共用线段         | 两条链路接在同一根竖线上，无法区分端口标签 | 为每条链路单独绘制连线；共享线段时，在分叉点明确标注   |
| 方框宽度不一致   | 同一行方框宽度不一致，端口标签无法保持对齐 | 默认 10 字符；需要绕线时扩展方框宽度，并保持同一行对齐 |
| 仅标一端端口标签 | 无法判断对端端口标签                       | 在链路两端分别标注端口标签                             |
| 端口标签错位     | 端口标签与竖线不对齐                       | 以竖线为基准居中对齐端口标签                           |
| 端口标签贴边     | 端口标签与方框间距小于 5.6 的规定值        | 按 5.6 保留固定间距                                    |
| 方框边框错误     | 左侧或右侧写成 `+`                         | 左右边框使用竖线，四角使用 `+`                         |
| 绕线穿框         | 连线穿过设备方框                           | 调整绕线路径，从方框外侧通过                           |
| 符号不统一       | 同一张图出现多种双向箭头                   | 统一使用 `<=>`                                         |
| 链路关系不完整   | 图中缺少端口标签或链路                     | 补全设备、端口标签和连线                               |

## 7. 自检清单

绘制完成后逐项确认：

- [ ] 每台设备都有独立方框；
- [ ] 方框宽度按 5.3 的规则确定，设备名居中，端口标签与引出线对齐；
- [ ] 每条链路都有两个端点；
- [ ] 两个端点都落在设备方框边界上；
- [ ] 链路两端都标注了端口标签；
- [ ] 端口标签与方框的间距符合 5.6 的规定；
- [ ] 各链路使用独立线段；需要共享线段时，分叉点已明确标注；
- [ ] 分叉点已标注，且分叉后的每个分支都能追溯到具体端口标签；
- [ ] 链路数量与链路清单一致；
- [ ] StreamPort 已标注，且连接线从设备间链路之外通过；
- [ ] 每台设备的已用端口数量在可用端口数量范围内；
- [ ] 图中完整表达了每台设备的接口和链路关系；
- [ ] 注释使用 `/** ... */`。
