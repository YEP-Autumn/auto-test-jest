# 20 堆叠命令

## 20.1 堆叠命令

### 20.1.1 `stack enable`

**功能**：使用这个命令来使能stacking，使用相应的no 命令去使能stacking,重启生效。

**语法**：

```
stack enable
no stack enable
```

**命令模式**：全局配置模式

**默认配置**：默认stacking enable 不使能。

**使用说明**：

使能stack 或者去使能stack 后并重启，端口相关的配置将被清空。

**示例**：

```
Switch# configure terminal
Switch(config)# stack enable
```

**相关命令**：无

### 20.1.2 `stack slot`

**功能**：使用这个命令来配置slot 编号，使用相应的no 命令来删除这个规则。

**语法**：

```
stack slot SLOTID
no stack slot
```

| 参数 | 说明 |
| --- | --- |
| SLOTID | 指定slot id 的值 <1-15> |

**命令模式**：全局配置模式

**默认配置**：默认stack slot id 不设置。

**使用说明**：

无

**示例**：

```
Switch# configure terminal
Switch(config)# stack slot 15
```

**相关命令**：无

### 20.1.3 `stack domain`

**功能**：使用这个命令来配置设备的堆叠域编号，使用相应的no 命令去配置默认堆叠域编号。

**语法**：

```
stack slot ( SLOTID | all ) domain DOMAINID
no stack slot ( SLOTID | all ) domain
```

| 参数 | 说明 |
| --- | --- |
| SLOTID | 指定slot id 的值 <1-15> |
| DOMAINID | 指定堆叠域编号 <1-65535> |

**命令模式**：全局配置模式

**默认配置**：无

**使用说明**：

无

**示例**：

```
Switch# configure terminal
Switch(config)# stack slot 1 domain 10
```

**相关命令**：无

### 20.1.4 `stack priority`

**功能**：使用这个命令来配置stacking member 的优先级，值越大优先级越高，在进行stacking
  角色协商的时候会根据member 之间的priority 及mac 地址大小来进行角色选举，重
  启生效.

**语法**：

```
stack slot ( SLOTID | all ) priority PRIORITY
no stack slot ( SLOTID | all ) priority
```

| 参数 | 说明 |
| --- | --- |
| SLOTID | 指定slot id 的值 <1-15> |
| PRIORITY | 优先级的大小 <100-65535> |

**命令模式**：全局配置模式

**默认配置**：默认优先级为500。

**使用说明**：

无

**示例**：

```
Switch# configure terminal
Switch(config)# stack slot 1 priority 1000
```

**相关命令**：无

### 20.1.7 `stack release slot`

**功能**：使用这个命令删除指定的线卡。

**语法**：

```
stack release slot SLOTID
```

| 参数 | 说明 |
| --- | --- |
| SLOTID | slotid 值 <1-15> |

**命令模式**：全局配置模式

**默认配置**：默认stack release slot 不设置。

**使用说明**：

使用stack release slot 1 命令删除线卡后，如果堆叠口连线没有断开，slot 1 重启后仍
  会加入堆叠。如果堆叠系统需要恢复为单机环境，可以进行拆分堆叠操作。拆分堆叠
  首先需要去使能设备的堆叠功能，然后配置好每台设备的管理IP 并保存配置。拆除线
  缆后，手动重启即可拆分堆叠。启动之后的设备将保存stacking 系统下的非端口业务
  配置，端口相关的配置将被清空。

**示例**：

```
Switch# configure terminal
Switch(config)# stack release slot 1
```

**相关命令**：无
