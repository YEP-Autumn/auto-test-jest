# 测试用例设计模板（脚本编写前）

> 用途：在编写脚本之前完成测试用例设计。测试人员依据用例描述，使用手工、仪表、自动化脚本等方式均可完成复测。
>
> 使用说明：复制以下结构作为单个测试脚本的用例文档，将 `<...>` 替换为实际值；一个测试文档对应一个测试脚本，文档中的子用例与脚本中的 `test()` 一一对应；公共拓扑、预置条件、配置和清理在文档内统一描述。观测面说明见附录 A，判定标准与常用定时器见附录 B。
>
> 本文独立于测试框架、工具与脚本实现。用例正文使用设备 CLI 命令、拓扑参数和可观测现象描述；框架、库、函数、代码、正则等实现细节写入脚本。

## 附录 A：六个观测面

设计用例时至少覆盖下列观测面中的**三个**；P0 用例建议全覆盖。

| 观测面 | 观测内容 | 证据形式 | 判定建议 |
| --- | --- | --- | --- |
| 协议报文面 | BPDU / LACPDU / LLDPDU / R-APS / OSPF Hello / LSA / BGP Update 的字段、定时器、序列号 | 抓包文件 + 字段解码 | 逐字段校验报文字段、定时器和序列号，并保存抓包解码结果 |
| 协议状态面 | 邻居 / 会话 / 角色 / 状态 / 定时器剩余值 | `show` 回显 | 按完整状态值匹配（例如 `Disabled` 全词匹配），同时记录定时器剩余值 |
| 表项面 | FDB、VLAN、路由、LSDB、ARP、mroute、LACP 成员表 | `show` 回显 + 精确条目 | 同时校验表项、下一跳和出接口 |
| 转发面 | 收发包数、丢包、重复、乱序、VLAN tag、TTL | 流量发送/抓包统计 | 同时校验收发计数、丢包率、重复与乱序；丢包率判据写明比较方向 |
| 计数 / 告警面 | 协议计数、丢弃计数、trap、日志 | `show ... counters`、SNMP trap、日志 | 校验计数递增量和 trap 内容 |
| 恢复 / 资源面 | 收敛时间、回切、残留配置、表项释放 | 时间戳、清理后基线检查 | 校验收敛时间、回切结果、残留配置和表项释放 |

## 附录 B：判定标准与常用定时器

下表列出常见默认值，用于设计等待时间和判定窗口；执行时以当前配置值为准。

| 协议 | 常见默认值 | 建议判定 |
| --- | --- | --- |
| STP | Hello 2s、MaxAge 20s、Forward Delay 15s | STP 收敛 ≤ 30s；RSTP 点对点链路 ≤ 1s；MSTP 按实例分别判定 |
| ERPS | WTR 默认 5 min、Guard 默认 500ms、Hold-off 可配 | 单环单点故障倒换 ≤ 50ms（G.8032 规定条件）；回切按配置的 WTR |
| LACP | short 1s/3s、long 30s/90s | 成员故障倒换 ≤ 3s（short）；成员状态 Selected/Unselected 双向确认 |
| LLDP | 发送间隔 30s、TTL 120s、fast start 4 个 | 邻居在 TTL 内出现/老化；关闭后按 TTL 删除 |
| OSPF | Hello 10s、Dead 40s（广播网络） | 邻居 Full；收敛时间按设计目标，采用设计值判定 |
| IS-IS | Hello 10s、Hold 30s | 邻接 Up；Level 1/2 分别判定 |
| BGP | Keepalive 60s、Hold 180s | 会话 Established；收敛按设计目标；断链后按 Hold 时间判定 |
| VRRP | Advertisement 1s、Master Down 3s | Backup 接管 ≤ 3s（默认参数）；抢占按配置延迟 |
| BFD | tx/rx 间隔 × multiplier | 检测时间 ≤ 配置值；联动协议邻居/路由在检测时间内变化 |
| IGMP | Query 125s、Robustness 2 | 加入/离开后表项按配置老化；查询器切换后仍可学习 |

判定写法建议：

- 采用「步骤 N：对象 = 值」逐条描述，值与步骤一一对应；
- 数值判据写明单位与比较方向，例如「丢包率 = 0%」「收敛时间 ≤ 1s」「计数增加 ≥ 1」；
- 反向校验同时写明目标结果与边界现象，例如「丢包率应为 0%，并确认 `100% packet loss` 未出现」「历史日志中的 `Established` 作为排除项记录」；
- 设备能力覆盖可选特性时执行对应测试点；能力未覆盖时，结论写 `Blocked`，注明原因，待能力具备后补充执行；
- 清理结果计入判定；需要保留现场时，在用例中明确说明并记录位置。
